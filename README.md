# 🏎️ APEX RUSH

An adrenaline-pumping 2D top-down arcade racing game built with **Godot Engine 4**. Navigate tight corners, manage high-stakes power-ups, and outmaneuver rival AI across fast-paced circuit tracks.

🎮 **[Play Live in Browser](https://gianainza.github.io/APEX_RUSH/)**

---

## 📸 Overview

**APEX RUSH** brings classic arcade racing mechanics to life with responsive car physics, angular drift mechanics, and strategic item pickups. Compete against an adaptive rival racer across multi-lap circuits, dodging hazards and timing boosts to take the checkered flag.

---

## ✨ Features

- **Responsive Arcade Physics:** Top-down vehicle physics with drift mechanics, speed multipliers, and heading alignment.
- **Dynamic Rival AI:** Path-following rival with adaptive boost usage, obstacle recovery, and defensive deployment.
- **Power-Up Arsenal:**
  - ⚡ **Nitro Boost:** Instant burst of acceleration with animated exhaust trails.
  - 🛡️ **Shield:** Temporary barrier shielding against track hazards and rival collisions.
  - 🛢️ **Oil Slick:** Deployable obstacle that triggers sudden loss of traction and spin-outs.
- **Race Systems:**
  - Countdown sequence with synchronized audio cues (`READY`, `SET`, `GO!`).
  - Lap and position tracking with real-time UI counters.
  - Dynamic drift and collision sound effects.
- **Web-Ready:** Fully compiled for HTML5 / WebAssembly for immediate browser play.

## 🕹️ Controls

| Action | Primary Key 
| :--- | :---: | 
| **Accelerate / Drive Forward** | `W` |
| **Brake / Reverse** | `S` | 
| **Steer Left** | `A` | 
| **Steer Right** | `D` | 
| **Use Stored Power-Up** | `E` |
| **Pause Game** | `Escape` |

## 🛠️ Tech Stack & Assets

- **Engine:** [Godot Engine 4.x](https://godotengine.org/)
- **Language:** GDScript
- **Target Platforms:** Web (HTML5/WebAssembly), Windows Desktop (`.exe`)
- **Assets:** Custom pixel-art vehicle sprites, dynamic particle/animation frames, and spatial 2D audio effects.
